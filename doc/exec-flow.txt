*exec-flow.txt*  Number code lines in execution order

==============================================================================
INTRODUCTION                                                    *exec-flow*

exec-flow.nvim anchors code lines with numbers in the order you plan to read
them, and lets you jump through them sequentially, reorder them, and export
them to the quickfix list. Anchors live in memory only and disappear when
Neovim exits.

Commands (default names):
  :ExecFlowAdd      mark the current line
  :ExecFlowList     list anchors in a float
  :ExecFlowClear    clear all anchors
  :ExecFlowQf       export to quickfix

==============================================================================
SETUP                                                       *exec-flow-setup*

>lua
require("exec_flow").setup({
  keys = {
    add = "<leader>xa", list = "<leader>xl", delete = "<leader>xd",
    clear = "<leader>xc", qf = "<leader>xq", next = "]x", prev = "[x",
  },
})
<

All keymaps are disabled by default. `commands`, `label`, `to_editor` and
`panel` are all configurable.

==============================================================================
KEYMAPS                                                 *exec-flow-keymaps*

Inside the float:
  <CR>  jump to the anchor
  j/k   move
  d     delete the anchor
  J/K   change execution order
  c     clear all anchors
  q     close
